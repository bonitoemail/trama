O que os jogadores escolheram

Cada partida do Trama é anônima. Somamos as escolhas para ver onde os jogadores concordam, onde se dividem e o que apostam antes de a realidade decidir.

Isto não é pesquisa de opinião. Mostra como os jogadores do Trama escolheram, não o que o Brasil pensa.

Como contamos

Cada partida é um número aleatório guardado no navegador, sem nome, login ou IP. Uma partida conta uma vez em cada decisão.

Só mostramos uma decisão quando ela tem pelo menos 50 escolhas. Os capítulos mais novos aparecem quando chegarem lá.

Os números somam todas as versões do jogo. Uma cena que mudou de texto continua a mesma decisão.
